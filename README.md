# CyLab Security Academy | Solutions & Write-Ups

A centralized repository documenting my technical progression through the CyLab Security Academy (formerly picoCTF) curriculum. 

## 🚀 Overview
This project contains technical write-ups, vulnerability analyses, and custom automation scripts. All exploit scripts and solvers are developed entirely in **JavaScript (Node.js)** to demonstrate how full-stack web technologies can be leveraged for systems security, algorithmic decoding, and process automation.

## 📁 Repository Structure

* **`/Cryptography`**: JavaScript solvers for asymmetric and symmetric encryption challenges, including algorithmic scripts for Shift Ciphers and RSA key analysis.
* **`/Forensics/problem-set`**: File parsing scripts and data extraction methodologies used to uncover hidden flags within metadata and raw file structures.
* **`/General-Skills`**: Documentation on foundational Command-Line Interface (CLI) tools, Linux utilities, and environment configurations.
* **`/Vault-Door-Series`**: Reverse-engineering write-ups that deconstruct nested programmatic logic, loops, and array manipulations to bypass Java-based source code security protocols.

## 💻 Technical Focus
* **Language:** JavaScript
* **Core Concepts:** Automation, Reverse-Engineering, Cryptographic Math, Digital Forensics, Source Code Analysis
